# astrbot_plugin_xwdraw

集成远端 SD 绘图 API 的功能完整插件，支持文生图、图生图、预设管理等功能。

## 功能特性

- ✅ 文生图和图生图
- ✅ 支持高级参数（步数、CFG、尺寸等）
- ✅ 预设管理（角色、风格、服装）
- ✅ 自定义预设
- ✅ 完整的帮助系统

## 配置说明

在插件配置页设置以下参数：

- **api_url**: 生成接口地址（默认 `https://sd.loping151.com/api/generate`）
- **api_key**: Bearer Token（必填）
- **timeout**: 请求超时时间，单位秒（默认 60）

## 使用指南

### 📌 查看帮助

```
绘图帮助
xw帮助
xwhelp
```

### 🎨 基础绘图

**文生图：**
```
来点 <提示词>
小千来点 <提示词>
```

示例：
```
来点 1girl, solo, beautiful
小千来点 初音未来 赛博朋克
```

**图生图：**

在发送"来点"命令的同时附带图片，即可自动进行图生图。

```
[发送图片] 来点 <提示词>
[发送图片] 小千来点 <提示词>
```

示例：
```
[发送图片] 来点 add more details, cyberpunk style -d 0.6
[发送图片] 小千来点 enhance quality -d 0.5
```

### 🧪 测试功能

**测试绘图（不消耗配额）：**
```
测试来点 <提示词>
```
该命令会回显提示词和检测到的图片，用于测试插件是否能正确获取输入。

### ⚙️ 高级参数

在提示词中添加以下参数来控制生成：

- `-s <数字>`: 设置步数 (10-50)
- `-c <数字>`: 设置 CFG scale (3-20)
- `-w <数字>`: 设置宽度 (768-2048)
- `-h <数字>`: 设置高度 (768-2048)
- `-m <数字>`: 设置模型索引
- `-d <数字>`: 设置去噪强度 (0.0-1.0，仅图生图)

示例：
```
来点 1girl, solo -s 30 -c 7 -w 1024 -h 1536
```

### 📋 预设管理

**查看预设分类：**
```
预设列表
预设
presets
```

**查看具体预设：**
```
角色列表
风格列表
服装列表
```

示例：
```
角色列表
风格列表
服装列表
```

**查看预设详情：**
```
预设详情 <类型> <名称>
```

类型可以是：
- `character` 或 `角色`
- `style` 或 `风格`
- `costume` 或 `服装`

示例：
```
预设详情 style 赛博朋克
预设详情 角色 初音未来
```

### ⭐ 自定义预设

**添加预设：**
```
添加预设 <名称>|<内容>
```

示例：
```
添加预设 我的风格|beautiful anime girl, detailed eyes, soft lighting
```

**删除预设：**
```
删除预设 <名称>
```

示例：
```
删除预设 我的风格
```

**查看自定义预设：**
```
我的预设
自定义预设
mypresets
```

## 注意事项

1. 首次使用需要在插件配置中填写 `api_key`
2. 图片生成可能需要 30 秒到 2 分钟，请耐心等待
3. 如遇超时，可在配置中增加 `timeout` 值
4. 预设数据会缓存 5 分钟以提高响应速度
5. 自定义预设仅创建者或管理员可删除
