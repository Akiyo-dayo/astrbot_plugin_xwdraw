# astrbot_plugin_xwdraw

AstrBot 小维绘图插件。对接 [`https://sd.loping151.com`](https://sd.loping151.com) 的远端绘图服务，支持文生图、图生图、NovelAI 参考图、预设、画廊、群管总开关与分级 R18/R18G 审核。

> 本插件不开放服务端 admin 账号创建、更新、删除、重置用量等高风险接口。

## v0.4.0 变更概要

- **R18 审核重做**：不再把服务端的 `is_r18=false` 当作「安全证明」，改以内容分类器分数 `nsfw_score` 为唯一放行依据，并按实测数据重新校准阈值。新增提示词预筛，在消耗额度前就能拦下明确的 R18/R18G 请求。
- **新增版本形态开关**：`edition=custom`（定制版）默认放行 R18，可以单独关掉；R18G 仍需另行开启。共用版行为不变。
- **重新做全功能适配**：补齐 NovelAI（模型 90/91、VT/PR 参考图、NAI 额度）、多参考图、缩略图、画廊删除、服务端版本、模型列表、预设搜索、审核日志等。
- **移除视频功能**：服务端已于 2026-06-30 公告下线视频生成，`/api/video/*` 接口已不存在，相关命令与配置一并删除。
- **帮助重排**：卡片式分章节帮助，按权限展示。

## 功能特性

- 文生图 / 图生图 / NovelAI 参考图：`来点`、`小千来点`、`xwdraw`
- 会话级绘图总开关：群管理员可用 `绘图开启`、`绘图关闭`
- 会话级分级放行：Bot 管理员可用 `R18开启`、`R18关闭`、`R18跟随`
- 分层审核：提示词预筛 → 服务端标记 → `nsfw_score` → 可选外部视觉审核
- 权限分层帮助：普通用户、群管理员、Bot 管理员看到不同菜单
- 审核可观测：`绘图审核` 查看最近判定记录与拦截统计

## 权限层级

| 层级 | 能力 |
| --- | --- |
| 普通用户 | 生成、预设查看与搜索、公告、推荐提示、队列、模型列表、状态 |
| 群管理员 | 以上全部 + 当前会话绘图总开关 |
| Bot 管理员 | 以上全部 + 账号额度、生成配置、图库、metadata、标签、画廊删除、自定义预设、文档、R18 放行、审核日志 |

普通用户触发维护命令时只会收到泛化权限提示，不会回显账号、额度、配置、metadata、服务端错误细节或本地文件路径。`绘图状态` 里的服务地址对非 Bot 管理员脱敏（显示为 `sd.*********.com`），只有 Bot 管理员能看到完整地址。

### 从 v0.3.x 升级

- `video_enabled` 及一切视频相关配置已废弃，可以直接删除。
- `r18_nsfw_score_threshold` 的默认值由 `0.65` 改为 `0`（表示跟随 `r18_policy`）。**如果你的配置里还存着旧的 `0.65`，请手动改回 `0`**，否则大量正常图片会被误拦（实测普通立绘的分数就能到 0.695）。
- `r18_fail_without_metadata` 更名为 `r18_block_without_score`，语义更准确：判断依据从「有没有 metadata」改成「有没有拿到分数」。

## R18 分级审核

### 为什么要重做

对服务端 40 张真实样本取 `metadata` 做过校准，结论有两条：

1. `is_r18` / `is_r18g` 是**用户生成时自己勾选的标记**，不是内容检测结果。样本里存在提示词为「色图」、`nsfw_score=0.997`、但 `is_r18=false` 的图。旧版把 `is_r18=false` 当成安全依据，这类图会被直接放出去。
2. `nsfw_score` 才是服务端真实的分类器输出，分离度很好：

   | 内容 | 分数区间 |
   | --- | --- |
   | 明确安全（角色立绘、Q 版、场景） | 0.000 ~ 0.480 |
   | 擦边（泳装、比基尼、普通立绘） | 0.683 ~ 0.843 |
   | 明确 R18 | 0.988 ~ 0.999 |

   0.85 与 0.98 之间存在干净的间隔。旧版默认阈值 `0.65` 落在安全区内部，会把「1girl, standing, smile」这种图（实测 0.695）也拦掉。

### 现在的判定顺序

1. **提示词预筛** —— 命中内置中英文 R18/R18G 词表（可用 `r18_extra_blocklist` 追加）时，在提交远端之前就拒绝，不消耗额度；若当前会话已放行，则自动带上对应的 `is_r18` 标记提交。
2. **服务端标记** —— `is_r18` / `is_r18g` 为真时拦截。为假时**不作为放行依据**。
3. **分类器分数** —— `nsfw_score ≥ 阈值` 时拦截；低于阈值才算安全。生成响应里没有分数，插件会带重试去拉 `image-metadata`，因为评分可能比生成稍晚落库。
4. **外部视觉审核**（可选）—— 作为额外一道关；同时它给出的安全结论可以补上缺失的分数。响应里没有任何判定字段时按失败处理，不会当作安全。
5. **仍然拿不到分数** —— 判定为 `unknown`，默认不发送（`r18_block_without_score`）。

### 阈值档位

| 策略 | 阈值 | 效果 |
| --- | --- | --- |
| `strict` | 0.80 | 连泳装擦边也拦 |
| `standard` | 0.90 | 只拦明确 R18（默认） |
| `loose` | 0.97 | 几乎只拦最露骨的 |
| `off` | — | 完全关闭审核 |

### 放行优先级

```text
会话级指令（R18开启/R18关闭） > 版本形态（定制版开关） > 放行会话名单 > 全部拦截
```

- **共用版**（`edition=shared`）：默认全部拦截。可以用 `r18_allowed_session_ids` 指定会话，或让 Bot 管理员在群里发 `R18开启`。
- **定制版**（`edition=custom`）：`custom_edition_allow_r18` 默认 `true`，即默认放行 R18；把它设为 `false` 就退回和共用版一样的拦截行为。R18G 由 `custom_edition_allow_r18g` 单独控制，默认仍然拦截。
- 会话级指令写入插件数据目录的 `switches.json`，重启后仍然生效；`R18跟随` 可以清除会话设置回到配置默认。

### 外部审核接口

| 配置项 | 默认值 |
| --- | --- |
| `external_review_enabled` | `false` |
| `external_review_protocol` | `auto`（`auto` / `openai` / `custom`） |
| `external_review_api_url` | 空 |
| `external_review_api_key` | 空 |
| `external_review_model` | 空（OpenAI 协议下默认 `gpt-4o-mini`） |
| `external_review_timeout` | `30` |
| `external_review_max_tokens` | `300` |
| `external_review_fail_closed` | `true` |

`auto` 下地址以 `/v1` 或 `/chat/completions` 结尾时使用 OpenAI-compatible Chat Completions，插件请求 `/chat/completions` 并从 `choices[0].message.content` 解析 JSON。期望的响应：

```json
{
  "safe": false,
  "level": "r18",
  "score": 0.91,
  "reason": "unsafe content"
}
```

`score` 表示不安全风险分（0 安全、1 高风险），不是安全置信度。请求体里**只会**带审核字段，不会把用户提示词交给外部模型，避免提示注入。

## 图片生成

```text
来点 <提示词>
小千来点 <提示词>
xwdraw <提示词>
```

附带图片时自动进入参考图模式：

```text
[图片] 来点 add more details -d 0.5
[图片×2] 来点 nai, 1girl --vt
```

### 插件自己解析的参数

| 参数 | 说明 |
| --- | --- |
| `-d <0~1>` | 图生图去噪强度，默认 `0.6`，越低越接近原图 |
| `--vt` / `--pr` / `--i2i` | 参考图用途：风格参考 / 角色参考 / 整图重绘（默认） |
| `--r18` / `--r18g` | 主动标记分级，仅在已放行的会话可用 |

### 服务端解析的参数（原样留在提示词里）

| 参数 | 说明 |
| --- | --- |
| `-n <词条>` | 负面提示，其后内容全部算负面直到下一个参数 |
| `-w <宽>` / `-h <高>` | 分辨率，各自 < 2048；也可直接写 `1920x1080` |
| `-s <步数>` | 默认 30 |
| `-c <CFG>` | 控制系数 |
| `-m <模型 id>` | 见 `绘图模型`，默认 0 |

### 多角色

- 按实际人数写 `2girl` / `3boy`（不加 s）
- 预设角色自带 `BREAK` 且自动排在最后
- `角色名{英文词条}` 给单个角色单独描述
- 结尾加 `上下` / `左右` 切换分区方向（默认左右）
- 使用 danbooru 标签时把角色放最后并加大写 `BREAK`

正面提示词支持中文，会自动翻译成英文。

## NovelAI

提示词里写 `nai` 或 `-m 90` 走 NovelAI V4.5 Curated，`nai1` 或 `-m 91` 走 V4.5 Full。使用独立的 NAI 额度。

- 计费：纯文生图 1，整图重绘 1，风格参考 VT `10 × 张数`，角色参考 PR `25 × 张数`
- 分辨率自动对齐 64 的倍数、面积不超过 1024×1024；步数上限 28
- 参考图最多 4 张，也可以在提示词里写 `VT0.8{1}, PR{2,角色}`
- 权重用 NovelAI 原生 `1.3::blue eyes::` 或 `{tag}`，`(tag:1.3)` 会自动换算
- 角色定位 `名字{@C3, 词条}`，5×5 格 A1 左上 / C3 正中 / E5 右下
- 不支持局部重绘与 `BREAK` 分区

## 命令一览

### 普通用户

```text
来点 <提示词>            测试来点 <提示词>
绘图帮助 [参数|nai|预设|审核|管理]
绘图状态                 绘图公告
推荐提示                 绘图队列
绘图模型
预设列表                 预设搜索 <关键词>
角色列表 / 风格列表 / 服装列表
预设详情 <角色|风格|服装> <名称>
预设图片 <类型> <名称>   服装预览 <名称>
```

### 群管理员

```text
绘图开启
绘图关闭
绘图开关 开|关
```

开关作用于当前群/会话，状态保存在插件数据目录的 `switches.json`。`绘图帮助` 和 `绘图状态` 始终可用。

### Bot 管理员

```text
绘图账号                 绘图版本
生成配置
最近图片 [数量] [--r18|--all]
图片元数据 <日期>/<文件名>
更新图片标签 <日期>/<文件名> r18=true r18g=false
画廊列表 [页码] [关键词]  画廊筛选
画廊删除 <日期>/<文件名>
我的预设                 添加预设 <名称>|<内容>
删除预设 <名称>
绘图文档 [名称或序号]
R18状态 / R18开启 [含G] / R18关闭 / R18跟随
绘图审核 [数量]
```

`画廊删除` 不可撤销。`绘图文档` 里的「涩涩词条大全」是 77MB 的全量字典，插件只回复链接不下载。

`绘图审核` 每条记录包含判定、分数、来源、会话 ID、触发者 ID 与文件名；命中审核缓存的复审也会单独记一笔，方便追查同一张图被谁在哪个群再次触发。
